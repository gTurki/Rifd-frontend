# رِفد RIFD — الواجهة (React + Vite)

تحويل تصميم عضو UI/UX (`index.html`) إلى React مربوط بالباك إند (Spring Boot).
الـ CSS والأيقونات والشعار والخريطة 3D منقولة من التصميم كما هي.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. داخل المجلد:
   ```bash
   npm install
   npm run dev
   ```
   يفتح على http://localhost:5173
3. رابط الباك إند في `.env`:
   ```
   VITE_API_URL=http://localhost:8080
   ```
   (غيّره لو الباك إند على جهاز ثاني، وأعد تشغيل `npm run dev`.)

الباك إند لازم يكون شغال، و `cors.allowed-origins=*` (الافتراضي) يسمح للواجهة.

## الحسابات (من DataSeeder، كلمة المرور `demo123`)

| الحساب | الدور |
|---|---|
| `operator1` | مشغّل مركز العمليات |
| `supervisor1` | مشرف (إدارة الموظفين، reset، حالة الأصول) |
| `C-101`, `T-101`, ... | موظف ميداني (اسم المستخدم = الرقم الوظيفي) |

الزائر يدخل من صفحة البداية بدون حساب.

## ملاحظات

- مع `security.enabled=false` كل شي يشتغل، والواجهة ترسل `actorStaffId` في كل إجراء.
  الاستثناء: تعديل «بياناتي» وتغيير كلمة المرور (`/auth/me`) يحتاجون `security.enabled=true`.
- التحديث المباشر عبر WebSocket (STOMP) على `/ws`. لو انقطع يظهر «غير متصل بالتحديث المباشر» تحت الساعة.
- الخريطة: كل منطقة في الباك إند مربوطة بمنطقة في التصميم (`src/map/geometry.js` → `ZONE_MAP`).

## هيكل المشروع

```
src/
  styles.css          CSS التصميم (بدون تعديل)
  extra.css           إضافات صغيرة (حقول السبب، عارض المرفقات)
  lib/api.js          كل الـ endpoints + التوكن + رسائل الخطأ { message }
  lib/ws.js           التحديث المباشر
  lib/labels.js       النصوص وتحويل قيم الباك إند لمفاتيح التصميم
  lib/svg.js          الأيقونات والشعار (من التصميم)
  store/AppContext.jsx  الحالة، تسجيل الدخول، التحميل، التحديث المباشر
  map/                الخريطة 3D (Three.js r128) + ربط المناطق
  components/         الهيكل (القائمة، الشريط، التنبيهات، النوافذ)
  pages/              الصفحات
```
